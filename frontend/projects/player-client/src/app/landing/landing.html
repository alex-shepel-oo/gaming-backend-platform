sports_esports The GBP Network

One backend for every game's economy

GBP is a shared backend that multiple games plug into: one player identity, one wallet, and currencies that convert between games through a common platform currency.

It's a solo-built portfolio project, not a production service — put together to show how I design and operate a real distributed system end to end.

What's under the hood

account_tree

Saga-orchestrated transactions

Currency conversion runs as an orchestrated saga across services, with automatic compensation if any step fails — no partial money movement.

monitoring

End-to-end observability

Every request is traced from the browser through the gateway into each service, correlated by user, and visualized in Grafana, Tempo, and Loki.

hub

Event-driven services

Services communicate over RabbitMQ with a transactional outbox, so events are never lost or double-published even if a service restarts mid-write.

cloud_sync

GitOps on Kubernetes

Every service ships independently through Helm and Argo CD — a commit is the only way anything reaches production.

security

Defense-in-depth auth

Short-lived access tokens, rotating refresh-token families with reuse detection, and instant admin-triggered revocation keep sessions honest.
